# 大肥鱼 · 自主陪伴与互动记录版 0.4.8

[下载 APK](https://github.com/ktao732084-arch/dafeiyu-android/releases/tag/v0.4.8) · [来源清单](SOURCE_MAP.md) · [逐文件溯源](PROVENANCE.json) · [验证记录](VALIDATION.md)

0.4.8让她根据已固定的人格、聊天、记忆和近期触摸记录，自主决定说什么、是否安静以及下一次何时考虑开口；删除旧的每天3次与30/90分钟限制，夜间安静改为可选。手账新增「最近互动」。称呼同步与此前兼容修复继续保留。

版本号与发布节奏遵循根目录的 [项目协作约定](AGENTS.md)。

记忆引擎已移植为安卓原生代码并打进 APK。存储、过滤、时间解析、去重、更正、归档和检索都由手机进程执行，默认启用；不需要电脑、Python 服务或 ADB。

模型辅助理解直接复用手机「模型连接」里已有的接口、模型和 Key。它用于理解同义表达、隐含变化与相关记忆，每轮可能增加模型请求（记忆不超过15条时全部直接进入上下文，「哈哈」「好的」这类闲聊也不做检索，均不额外请求）；没有模型或网络时继续使用本机规则。这里没有内置一个离线大语言模型。

本项目基于小小桌宠和社区大肥鱼项目整合，不是 DeepSeek 官方产品。代码采用 MIT；角色动画等第三方资源保留非商业约束，见 [ASSET_LICENSE.md](ASSET_LICENSE.md)。

## 安装与使用

1. 在 Android 8.0+ 安装 `dafeiyu-android-0.4.8.apk`。与0.2/0.3/0.4.0/0.4.1沿用同一体验签名，可覆盖安装保留数据。
2. 初次相遇时，手动选择一种性格或随机一次。确认后固定，后期没有重选人格入口。
3. 「模型连接」默认选择 **DeepSeek V4.1 Flash**。点「去 DeepSeek 官网获取 Key」，登录后创建并复制 API Key，回到 App 粘贴（或点「粘贴剪贴板里的 Key」），点「连接并保存」即可。地址和模型自动填写，测试成功才保存；API需有可用余额，测试与聊天会使用自己的额度。其他服务商选「其他模型 / 自定义」，旧配置保留。
4. 「记忆手账」查看、搜索、编辑、固定或忘记记忆，可只看自己写的或聊天里自动记下的；「共同经历与记忆变化」查看历史。无需额外设置记忆服务器。
5. 可先不配置模型，用 `记住：我喜欢海边散步` 测试手机本地记忆。时间解析、明确更正和归档离线可用。
6. 想悬浮显示时，开启显示在其他应用上层和通知权限，再点「让她住到屏幕上」。选好性格后，首页会列出还差的两步（接通模型、把她放到桌面上），完成或点「不再提示」后不再出现。桌面上的她全部隐藏后，后台服务和常驻通知会一起停止。

从0.3升级时，旧电脑服务地址不会自动激活。手机内置引擎是默认运行路径；人格与已保存的记忆保持原有数据。

## 养成主线（0.5.0，待发布）

她是一条从深海游上来的小鲸鱼。和你的共同经历会变成「回忆泡泡」，攒进她的泡泡瓶；泡泡越多，她想起的关于自己的事越多。主线分五章：初遇、熟悉、默契、信任、羁绊，每章要求**羁绊值**和**相识天数**都达到，并在桌面上和你一起经历一段剧情。完整设计见 [养成主线设计](docs/GROWTH_DESIGN.md)。

- **怎么变亲近**：每天第一次见面、聊满3轮、喂食（每天3次）、摸摸（每天5次）、新记下的事（每天3条）、看她带回的明信片。聊天一天只算一次，不会因为多聊多花 API 费用；离开不扣分；模型回复不能加分。成长记录可在「我们的故事」逐笔查看。
- **长按菜单**：聊天 / 喂食 / 动作 / 出门 / 更多（大小、我们的故事、隐藏）。喂食用小鱼干，白饭永远免费；小鱼干只能靠互动获得，不能用钱买。
- **出门**（第2章起）：带个便当送她出门1–4小时，她会收在屏幕边上；点边上的标签或和她聊天就会提前回来，带回一张明信片。三天以上没见面，她会自己出去转一圈，只留一张明信片。
- **动作解锁**：新伙伴的动作随章节解锁，动作菜单显示「第N章解锁」；作息、点击、睡觉、节日和季节动作始终可用。从0.4.x升级的伙伴保留全部原有动作（含蓝鲸现世），按已有记录估算所在章节。
- **剧情只用真实记录**：剧情会引用你亲口说过的话（本机记忆原文），不额外请求模型。忘记记忆或清空聊天时，对应泡泡会破掉，章节回忆里的引用也一起去掉；羁绊和章节不回退。

## 称呼只设置一次

可以直接说「我叫kk，以后就叫我kk吧」；本轮保存成功后，称呼会同步到「名字与称呼 → 她怎么称呼你」。手动修改也会用于之后的聊天。升级时空设置可从已有明确称呼记忆补入一次，非空设置保留；手动清空后不从旧记忆反复恢复。模型猜测、历史引用和失败/取消的请求不会改称呼。

「陪伴设置」不再重复放称呼输入框。复杂表达可手动填写；详细规则见[称呼同步说明](docs/NICKNAME_SYNC.md)。

官方入口：[创建 API Key](https://platform.deepseek.com/api_keys) · [查看余额/充值](https://platform.deepseek.com/top_up)。这些入口在 App 内也有按钮。

按2026-10-28的[官方文档](https://api-docs.deepseek.com/zh-cn/)预置 `https://api.deepseek.com`、`deepseek-flash`（DeepSeek V4.1 Flash）；日常聊天、连接测试与原生模型记忆统一使用非思考模式。网页聊天免费不代表API免费，收费规则见[官方说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

连接时会实际请求一次模型，确认收到文本回复后才保存；随后查询DeepSeek官方余额，成功结果页展示余额并可直接开始聊天。设置页提供「刷新余额」，显示可用总额、充值余额和赠金，人民币和美元分别显示；已缓存结果标注查询时间，不宣称实时。余额查询失败会显示未知，不冒充0余额；模型实测成功时仍可保存使用。其他服务商暂不支持统一余额查询。

新手只填写 Key。连接失败不覆盖旧配置；取消或超时后迟到结果不保存。切换服务商会清空未保存的Key，也不会复用其他服务商的已保存Key。自定义模式仍可独立测试、保存接口。

## 手机端能力

- **本机运行**：`NativeMemoryEngine` / `NativeMemoryTime` / `NativeMemoryRules` 执行原生记忆处理，不启动 Python、不调用本地电脑端口。
- **写入**：除了「记住：」和聊天模型逐字摘录的原话，本机规则也会从你的每条消息里认出值得记的话（身份、偏好、习惯、家人宠物、学习工作、带日期的计划、近况变化），不再全靠模型主动摘抄；问句、假设、密钥和「我在吃饭」这类一时状态不记。每轮最多3条，仍经过去重与更正处理。规则评测：盲测语料抓到22/25条事实、25句闲聊误记2句（`tests/memory-capture`）。
- **陪伴日记**：默认开启，可在陪伴设置关闭。前一天聊过至少3轮时，下次聊天回复完后在后台用一次模型请求写下她的一两句日记（同一天只尝试一次，不拖慢聊天）。聊天时带最近两篇和相关的旧日记，并注明是她的概括、可能不准，以你的原话和记忆为准。可在手账「她的日记」查看和清空；忘记相关记忆、清空聊天时一起删除。
- **往事回忆**：每条消息都会在全部聊天记录（包括移出近期窗口的历史）里找最相关的5段往事，连同日期、你当时的原话和她的回复一起参考，可以自然接上「你上次说……」。只在本机检索，不额外请求模型；忘记和清空会同步删除。
- **依据与时间**：保留用户原话与直接来源，解析文本另存；按说话时的日期与时区解释相对时间，事件结束后归档。
- **变化与历史**：明确更正使旧记录失效，重复信息合并并保留来源；历史不作为当前事实，明确询问过去时才带历史标记引用。
- **模型辅助**：`NativeMemoryIntelligence` 默认复用已有聊天模型，选择相关记忆 ID，或判断新增/重复/取代。不能自行编造记忆原文、ID或设备操作；一批判断校验通过才应用，失败退回本机规则。
- **语义检索**：手机版默认使用当前聊天模型按含义选择记忆，不要求另配向量服务。关键词检索始终可在本机运行。Python/ONNX 向量方案保留用于可选开发对照，不是手机运行条件。
- **一致性**：聊天、记忆和情绪原子保存。取消、修改配置或清空记忆后，迟到结果不能写回。删除记忆清理关联版本、直接来源对话、相关整理记录、缓存和备份。
- **容量**：最多500条活跃记忆、1000条历史归档、512条整理事件、160轮近期对话；每次回复仍只带最相关的约15条，模型辅助判断和检索只看有上限的候选清单（约40条/80条），不会因记忆多而变贵。记满时替换最早的非固定条目。可选的电脑 Python 服务协议仍限120条，超过时自动使用手机内置记忆；模型工作状态以4MiB UTF-8限额控制。移出近期窗口的完整对话另存本机历史文件，按页读取，不再因超过160轮自动丢弃；长期保存受手机剩余空间约束。
- **人格与表现**：5种初始化性格，7种情绪映射到动画；名字和称呼可改，冻结的人格不会被记忆判断改写。
- **主动陪伴**：总开关默认关闭，已有选择保留。开启后由模型结合人格、聊天、相关记忆与近期触摸决定开口或安静，并安排下次考虑；无每日次数上限，夜间安静可自行开启。仍遵守可见、亮屏解锁、系统勿扰和聊天优先；保留2分钟防循环间隔。每次主动考虑都可能产生API费用，包括选择安静时。记录与规则见[主动陪伴说明](docs/PROACTIVE_COMPANION.md)。系统回收后尝试恢复已显示的桌宠；强制停止或厂商清理后需手动开启。

「陪伴设置 → 记忆引擎」默认展示手机内置能力和模型辅助开关。可选的 Python 对照入口「开发联调」默认隐藏，长按该页第一段说明后显示，说明见 [memory-service/README.md](memory-service/README.md)。

## 直接问她过去聊过什么

0.4.5把完整历史接入回复流程，不必先打开聊天记录页。可直接说：

- 「我们上周聊过什么？」
- 「昨天聊过的那个电影叫什么？」
- 「上周三说了什么？」
- 「2026年10月19日到10月25日聊过什么？」

App在手机本地解析时间范围，查询近期和归档对话，筛选有日期与来源ID的原文摘录，再使用已配置的聊天模型回答。上周按设备时区的上一完整周（周一至周日）计算，支持昨天/前天、上上周、上个月、最近若干天、具体日期与日期范围。范围不明或日期无效会先澄清。

不是一次性上传全部历史：每次最多检查1000轮或8MiB内容，最多提供24条、约14000字符的检索证据。超过范围会标记部分结果；普通问候不触发历史扫描。话题未字面命中时，会给模型同一时间范围内的候选摘录作判断，不能据此宣称该主题肯定聊过。

没有记录时直接说明未找到，不能推断当时没聊过；旧版已淘汰、已清空或忘记的来源无法找回。未展示回复不当作已说出；旧版展示状态缺失时只标作「保存的回复」。历史原话里的昨天/明天按当条发送日期解释，旧观点不自动当成现在的事实。

关闭「记住重要的事」仍可按你的明确提问查询自己的聊天记录，这不会重新提炼或写入长期记忆。历史检索本身不调用额外模型；已有模型负责归纳。未配置模型时仅显示本机原文摘录，不能提供模型归纳。

## 分段回复与聊天记录

- 日常回复在本机按句意拆成1–3段，短回答保持一段；复用同一次回复，不额外调用分段模型；原有智能记忆请求仍可能发生。每段留3.5–10秒阅读时间，桌面保留最近两段；聊天页里每段是一个单独的气泡。界面在完整回复保存后逐段呈现；陪伴设置的流式开关只控制接口接收方式。
- 新消息、收起聊天页、隐藏桌宠或息屏停止相应展示队列。剩余段落保留在历史中，标注未展示；模型上下文不把未展示的话当作已经说给用户听。
- 长回复、代码和链接可点开全文；点桌宠气泡、首页「和她聊聊」或「最近聊天」进入聊天页。长按消息可复制；长按你自己的话可「让她记住这句」。
- 历史按日期分组，每次加载20轮，支持更早记录、日期筛选、关键词搜索（你说过的话和她展示过的回复，点结果回到当时）和回到最新。筛选使用当前时区，消息时间按记录时区显示。
- 新记录保存稳定ID，发送/回复完成/首次与最后展示/每段展示的毫秒时间戳，以及时区与偏移。字段说明见 [聊天记录格式](docs/CHAT_HISTORY.md)。
- 保留已有记录；旧版已经淘汰的内容无法恢复，不补造旧记录缺失的完成和展示时间。失败或取消的未完成回复不作为完整回复保存，输入恢复为草稿。
- 清空聊天同时清理近期与历史；忘记记忆也删除其直接来源聊天。历史不整份上传给模型；现有手账导出暂不包含全部历史文件。

## 作息、互动与人格一致性

- **作息动作**：按设备本地时间选择早间洗漱、早餐、工作日忙碌、午饭、午后犯困、下午茶、晚饭和晚间玩耍。季节与节日也影响动作；使用角色现有动画，随机选择并设置冷却，不保证某一时刻必播某个动作。
- **夜间睡觉**：0–6点循环打盹。轻触、拎起或聊天可以叫醒她，清醒10分钟后重新按作息睡觉。连续轻触、吃东西或忙碌时被打断都有对应反应；从0.4.8起近期交互带时间保存，普通聊天与主动消息可参考最近12次，手账可查看最近200次；升级前未记录的触摸无法补回。
- **人格一致性**：保留初始化冻结的人格，增加固定自我设定和每种性格5段口吻示例；按实际聊天天数调整熟悉程度。回复中的自我陈述逐字保存，可在手账查看或清空。历史陈述不能覆盖初始化人格。
- **聊天兼容**：支持流式接收（自定义接口不支持时可在「模型连接 → 其他模型」里关闭）、普通文本回复、JSON前缀处理、严格角色交替和推理模型的较大输出额度。历史窗口8–11轮，较早回复压缩；检测重复口吻并在下一轮提醒。稳定提示词放在前面，动态背景放到最后，便于服务商缓存。
- **关键记忆**：过敏、忌口、用药、身份及固定条目中最多5条持续进入上下文，再补充相关记忆。默认使用手机原生引擎。
- **省电与恢复**：息屏停止桌宠定时任务并暂停视频；锁屏或打开主界面时暂停视频解码。息屏不打断用户已发出的聊天，只取消主动请求。实际耗电、厂商后台恢复和视频效果仍需真机验收。

## 数据与边界

记忆和对话保存在 App 私有目录，关闭系统备份，Key 使用 Android Keystore AES-GCM 加密。启用模型辅助时会将查询和相关记忆发给你配置的模型服务商；无开发者中转服务器。手账导出不含 Key。自行导出的文件和模型服务商的数据不由 App 删除。开启陪伴日记时，前一天的对话（你的原话和她显示过的回复）每天最多一次发往同一模型服务商用于写日记。

不包含语音、跨 App 读取、设备自动操作或人格自主训练。仍需真机安装、浮窗、视频解码、系统Keystore和耗电验收。Robolectric、离线规则评测与受控模型测试的边界见 [VALIDATION.md](VALIDATION.md)。

## 构建与复现

JDK17、Android SDK Platform34、Build Tools36.0.0、PowerShell7；无需 Gradle。签名私钥不随源码分发：

```powershell
$env:XIAOXIAO_STORE_PASS='你的签名密码'
./build.ps1 -Sdk 'D:/Android/Sdk' -Jdk 'C:/Program Files/Java/jdk-17' -KeyStore 'D:/Keys/fish.keystore'
./tests/run-core.ps1 -Jdk 'C:/Program Files/Java/jdk-17' -JsonJar 'D:/test-libs/json.jar'
./tests/robolectric/run-tests.ps1 -AndroidRoot '.' -Sdk 'D:/Android/Sdk' -Jdk 'C:/Program Files/Java/jdk-17'
```

产物为 `build/dafeiyu-0.5.0.apk`（versionCode 13）。原生规则由 `tools/generate-native-memory-rules.py` 从已固定的上游源码 AST 生成，不执行 Python 引擎；生成后的 Java 常量随 APK 编译。

`NativeMemoryTest` 在不启动Python服务的条件下运行84个共享场景，并覆盖默认设置、旧版升级、离线更正、模型配置复用、非法输出回退、批量原子性、时区和删除竞态。`MemoryIntegrationTest` 另保留Python HTTP对照；普通用户运行App不需要这些测试依赖。

Linux/macOS 可运行 `tests/run-core.sh path/to/json.jar path/to/android-all.jar`，以 Android 14 框架类执行全量编译和核心检查，无需 Android SDK；`.github/workflows/check.yml` 同时校验记忆服务与共享84场景基线。
