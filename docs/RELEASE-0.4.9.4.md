# 大肥鱼 0.4.9.4 · 自然短气泡与互动回应

这次只递增最后一位，把主分支最近的改动合并到一个安装包。

- **回复更自然**：聊天与桌宠共用短气泡分段，识别句号、逗号、省略号与破折号停顿。旧聊天重新排版，原文和已展示状态保留。
- **碰她会回应**：连续摸摸、挪动、抛起或喂食后，等松手与动作结束，她会按自己的性格接一句短话。陪伴设置可单独关闭；使用已连接模型的额度，忙时、专注、聊天和剧情优先。物理互动保留最近200条。
- **五子棋入口不乱弹**：只有明确想玩或邀请时，聊天里才出现一个对局入口；查询战绩、讨论规则或只是提到五子棋不会触发。落子改为同一点再点一次确认；她会结合人格、心情和棋局记录选择本局棋力，选择过程可能使用一次模型请求，逐手落子仍在本机计算。
- **界面与养成精简**：首页按「我们」「设置」整理，每项功能保留一个主要入口。养成只保留羁绊值、章节、剧情与动作，喂食免费；去掉小鱼干、旅行、明信片与便当。升级清理这些已移除功能的旧字段，保留羁绊、章节、回忆、图鉴与成长记录。

沿用原签名覆盖安装，保留模型配置、人格、聊天、记忆和棋谱。同步提供GitHub Release与国内HTTPS更新源；已安装用户可在「关于 → 检查更新」获取新版。

验证采用Android 15模拟器、真实产品DEX、横竖屏界面与受控模型回归；不等于所有实体手机或所有模型的效果。完整结果见[验证记录](https://github.com/ktao732084-arch/dafeiyu-android/blob/v0.4.9.4/VALIDATION.md)，代码与素材来源见[来源清单](https://github.com/ktao732084-arch/dafeiyu-android/blob/v0.4.9.4/SOURCE_MAP.md)。
