# 大肥鱼 0.4.9.5 · 润色保真与记忆修正

本次仅递增显示版本号最后一位，Android versionCode 升为 19，沿用原签名覆盖安装。

- **润色保留原意**：明确提供原句的润色请求在展示前增加保真校对，核对否定、程度、人物归属、日期、数量和条件。最多修正一次，无法确认或校对失败时保留原文；未通过的草稿不会先显示或写进聊天记录。普通闲聊不增加这一步。
- **保留傲娇特色，改善表达**：保留五种人格及其示例，调整聊天采样和表达要求；“只给一句、不要点评”时优先交付所要文本。
- **记忆更可靠**：减少把代写素材、临时指令、问句中的猜测当成用户事实；相关的有效纠正原话优先于她以前的猜测。原聊天、手写笔记与已保存数据保留。
- **连续补话与口头禅**：回答中可以继续补充，尚未完成的请求会合并处理；通过日记从真实用户原话提炼少量说法，合适时借用。失败或取消后保留草稿。
- **桌宠与首页**：互动回应只留在桌宠气泡和记忆中，聊天页不再插入；首页角色使用动画，角色说出的部分动作会与桌宠表现对应。
- **章节任务线**：主线改为五章任务线，展示下一步目标和进度，章节开场白与回应随原有人格变化。

润色校对使用已连接模型的额度，通常额外一次请求，修正时最多两次。关键片段检查较保守，因此有时会保留已经清楚的原句。保护针对能明确提取原文的润色请求；翻译、多段来源不明或明确要求改变事实的任务不套用原句锁定。模型校对不是所有语义的绝对保证。

新版同步提供 GitHub Release 和国内 HTTPS 更新源。已安装用户可在「关于 → 检查更新」获取；无需重新配置模型、人格、记忆或棋谱。

验证使用 Android 15 模拟器、产品 DEX、框架与运行时回归，并对现有真实模型做针对性复测；不代表所有实体手机和所有模型。验证记录见 [VALIDATION.md](../VALIDATION.md)。
