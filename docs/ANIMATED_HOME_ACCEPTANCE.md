# 首页动画合并验收（PR #22）

2026-10-29，将Claude的`ui/animated-hero`对齐当前main。更新记录保留双方条目，溯源清单按合并后的文件重新生成；保留主分支人格状态、动作表达与互动回应不进聊天的改动。未递增版本、未发布安装包。

补修首页复用播放器后动作解锁集合不更新的问题：首页重绘时读取最新章节的可用动作，播放器实例仍复用。新增章节变化后无需重启就能使用新动作的界面回归。

新增独立Android验收入口`HeroPetInstrumentation`，检查真实MediaPlayer和EGL画面：待机播放推进、首帧替换静态立绘、重复render复用、点击回应、Activity退后台实际暂停、返回继续、退出释放渲染线程。Android15/API35模拟器24项检查通过，截图人工核对；测试使用独立包`com.dafeiyu.herochecks`和合成数据，不访问真实模型Key，不覆盖正式App，结束后清理独立包。

产品编译与签名通过；实际产品DEX的20组核心检查和63项独立Android运行时检查通过。相关141项框架回归最终通过（含修正断言后的7项复测），覆盖首页、聊天、五子棋、养成、人格、记忆、调度及更新。原先主分支一条测试仍要求旧提示词「初始化人格」，而现文案为「初始人格」；断言改为同时接受两种表述，仍检查冲突时优先初始人格的约束，生产提示词未改。

本轮未重跑Python HTTP记忆服务的84场景回放（本PR不改该服务或客户端），也不把模拟器结果表述为全部实体手机兼容。关闭系统动画的静态分支按原实现保留；没有改变系统时间来伪造夜间播放。
