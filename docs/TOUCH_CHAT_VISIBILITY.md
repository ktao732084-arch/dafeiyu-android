# 互动回应仅留桌宠气泡 · 2026-10-29

按用户要求，物理互动回应仍保存动作证据、回应原文与展示回执，模型上下文继续参考；聊天列表不再呈现这类轮次。本轮源码尚未正式发布，公开0.4.9.4及其验收哈希不变。

`conversationRange`在分页计数之前排除带`interaction`标记的记录，覆盖近期与归档。聊天首页、翻页、日期筛选、搜索跳转、时区说明与首页聊天预览使用该查询；模型历史、原始归档及时间范围回忆仍使用原查询。无需改写或删除旧记录，旧版已经保存的互动也立即适用。普通聊天和闲时主动消息继续显示。

聊天搜索原本只索引带用户文字的轮次，物理回应不在其中。渲染与全文入口额外防止旧引用展示互动。互动气泡末尾不再提供聊天入口，点击只收起当前气泡；正常聊天气泡的跳转保持原行为。

- Android15/API35模拟器产品DEX：19组核心套件通过，其中互动33项检查覆盖近期/归档混合、超过一页的隐藏互动、游标、日期与持久记录保留。
