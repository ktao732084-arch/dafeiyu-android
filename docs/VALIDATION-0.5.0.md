- 新增 GrowthTest 3617 项检查：
  - `story.json` 与动画目录一致：每个动作都有章节，引用的动作都存在，每个月至少 30 个旅行地点。
  - 每日上限：聊一百轮和聊三轮得到的一样多；时间往回拨不重复发奖；成长记录有上限，而且合计不变。
  - 章节需要羁绊值和天数两个门槛；不衰减；长时间离开只留一张明信片。
  - 解锁：节日、季节、作息、睡眠动作始终可用；每种情绪在第 1 章都有可用动作；老用户保留全部动作。
  - 喂食：价格、白饭免费、每日上限、饱腹状态。
  - 泡泡：当天的新记忆加分；记忆被归档时保留引用；被忘记或清空时去掉引用，羁绊值和章节不回退。
  - 剧情：只引用真实记忆，没有记忆时用备用台词，自定义人格不出现鲸鱼设定，没有残留占位符，奖励只发一次。
  - 旅行：未解锁、便当价格与退回、提前回来、按时回来、季节地点、明信片上限。
  - 旧版回溯：估算值、天数上限、补记卡、自定义人格。
  - 提示词：关系阶段跟随章节，设定只到当前章节，并且放在可缓存的 system 段。
  - 待机动作：从不播放未解锁的动作，饥饿和饱腹会调整权重。
  - 存储：新安装和升级的区分、保存后重新读取、文件损坏时从备份恢复。
