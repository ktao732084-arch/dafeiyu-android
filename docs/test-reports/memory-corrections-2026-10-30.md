# 记忆更正与回复完整性回归（2026-10-30）

基于 main `14cdba6`，修复分支 `fix/memory-correction-utf8`。保留既有小声嘀咕、共同经历、人格及采样设置。版本仍为 0.4.9.5/code19，仅用于本地验证，未发布到 GitHub 或国内更新源。

## 变更

- 模型省略记忆字段时，本地仍捕获常见习惯陈述和明确更正；完整更正及相邻范围说明优先于截断摘录。
- 支持不带“这/下”的星期表达，取消和替代日期不再混用；“从旧时间改到新时间”优先采用新时间。
- 阻止复述指令、练习结束语进入用户事实；已有同类非手动记录不进入普通事实召回。
- 严格 UTF-8 解码、损坏字符检查、一次有上限的恢复请求；取消和连续失败均不保存损坏回复。
- 历史及近期互动摘要等使用上下文副本屏蔽损坏文字，不篡改原记录。
- 兼容末尾嘀咕标签，流式正文不露出标签，开关仍有效；用户要求的代码和原样输出保留。

## 真实模型

使用模拟器已有配置的 DeepSeek Flash 与经典人格，独立记录中共完成 **40 轮迭代聊天**。不是最终构建单独聊满40轮：中间按复现结果补强，最终构建补测4轮；其余变化分别经过前面迭代的真实聊天和最终受控回归。一次启动时聊天窗口未获焦点，未发送到模型，不计入40轮。

核对了实际记忆文件和请求上下文，而非只看回复是否说“记住了”：旧饮品、旧时间及旧通勤方式均有替代来源；隔12轮闲聊并重启后仍召回更正结果；改期的 event_date 为替代日期；最后两条任务指令没有新增记忆，已有同类指令没有进入事实召回。

40轮未出现 U+FFFD。迭代中一次未请求的嘀咕标签泄漏已加入受控回归并修复；最终真实代码原样输出保留。两条明确润色任务保留原句，证明本轮限制未被改动，不等同于润色质量高。

傲娇、独立偏好和受夸时别扭的语气仍在。自然中文仍偶有拗口、夸张联想；没有声明彻底消除病句，也没有削弱人格来换取规整文本。未覆盖实体手机、其他人格或所有复杂时间语义。

五段测试分别校验原设置、原聊天及成长文件未变；测试辅助包已卸载，正式应用恢复普通界面。真实对话、截图、原始请求和逐轮状态只保存在本地，不提交仓库。
