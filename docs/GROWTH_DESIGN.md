# 养成主线：深海来的小鲸鱼

> 现行规格（2026-10-29）。只有一条养成主线，做成**五章任务线**：每章有一件要一起做的事（做到其中一条就行）和一个泡泡瓶门槛，两样都满足就进入下一章；进入时她会回应你刚做过的事，再说出新一章要做什么。
> 小鱼干、出门旅行、明信片和便当已经去掉，见 §8。为什么这样设计，见 §11。

## 1. 一句话

和她相处的真实经历会变成「回忆泡泡」，攒进她的泡泡瓶。每一章她都会请你和她一起做一件事：告诉她一件关于你的事、陪她下一局五子棋、天天来看她、下赢她一局。做完了，泡泡瓶也够满了，她就会想起更多关于自己的事。走到第五章，她会想起自己真正的样子。

养成的是**你们的关系**，不是她的人格。人格在初次相遇时冻结，这一点不变。

## 2. 原则

1. **只有一个数：羁绊值，界面上就是泡泡瓶。** 「泡泡瓶 180/250」就是羁绊 180、下一章要 250，没有第二个泡泡计数。
2. **每章只有一件事，而且总有第二条路。** 不想下棋、关了记忆的人，靠见面或聊天的天数也能走完。目标做到后锁定，之后删掉记忆或棋局也不会退回。
3. **不鼓励多聊。** 每轮聊天都花用户自己的 API 费用，所以聊天一天只算一次。其余来源都是本机的免费互动。
4. **离开不扣分。** 羁绊值只增不减，没有饥饿、生病、断签。她不说让人内疚的话。
5. **模型不能加分。** 羁绊值、章节目标、解锁只由本机规则根据已提交的记录计算：记忆手账、聊天记录、见面记录和五子棋的实际棋谱。
6. **离线可玩。** 剧情是固定剧本，插入本机记忆原文，不额外请求模型。
7. **老用户不倒退。** 已经能看到的动作不收回，已经到达的章节不回退。

## 3. 世界观

她是一条从深海游上来的小鲸鱼。深海又暗又安静，鲸鱼会把记住的事装进泡泡里，可她在海底时吐出的泡泡总是空的，因为一个人待着，没什么可以记住。

她顺着一束光游到海面，变成了现在这个小小的、看起来有点肥的样子，住进了你的屏幕。和你在一起以后，吐出的泡泡第一次装上了东西。她把它们收进**泡泡瓶**，隐约觉得瓶子装满时，会想起自己原本的样子。

结局（第五章）：她短暂地变回了一头蓝鲸（`蓝鲸现世`）。「原来我本来就这么大，才不是肥，只是还没长回去。」但她选择变回小小的样子留下来。之后泡泡瓶改叫「我们的海」，可以一直攒下去。

这和 `selfCanon` 一致：她喜欢吐泡泡，被叫「大肥鱼」时嘴上反驳；设定里不出现任何家人或同伴。

**泡泡瓶**显示的就是羁绊值：每一次见面、聊天、喂食、摸摸、新记下的事和章节剧情，都往瓶子里放泡泡。章节回忆里引用的原话在原记录被忘记、清空时一起去掉；泡泡瓶和章节不受影响。

**提示词里的设定**按章节累积注入（`Growth.lore()`，放在 system 段，可缓存），只到当前章节为止：

| 章 | 设定 |
|---|---|
| 1 | 我从深海游上来，喜欢吐泡泡。泡泡是什么，我自己也还说不太清。 |
| 2 | 我开始习惯海面上的光了。我吐的泡泡里，开始装着和你有关的事。 |
| 3 | 我有一只泡泡瓶，每个泡泡里是一段和你的回忆。瓶子装满的时候，我好像会想起自己原本的样子。 |
| 4 | 深海很暗很安静，我以前一直一个人待在那里，所以以前的泡泡总是空的。 |
| 5 | 我其实是一头蓝鲸，变回去过一次，但我选择小小地留在你身边。 |

自定义人格不注入设定，剧情改用中性台词。

## 4. 羁绊值

| 行为 | 羁绊值 | 每天上限 |
|---|---|---|
| 今天第一次见面（轻点她、打开首页或发出一条聊天） | +5 | 1 次 |
| 今天聊满 3 轮（只算提交成功的你的轮次；主动消息、历史检索提问不算） | +10 | 1 次 |
| 喂食 | +2 | 3 次 |
| 摸摸（连戳惹她生气的那次不算） | +1 | 5 次 |
| 新记下一件事（当天写入的记忆） | +3 | 3 次 |
| 章节剧情播完 | +20 | 每章一次 |

日常每天最多 35 点。一天的分界按手机时区；时间往回拨不重复发奖。

## 5. 章节：五章任务线

每章 = 进入时的剧情（回应你刚做的事）+ 她的开场白（说出这一章要做什么）+ 这一章的事 + 泡泡瓶门槛。**这一章的事做到其中一条，并且泡泡瓶装到下一章的门槛**，就进入下一章。

| 章 | 开场白 | 这一章的事（做到其中一条就行） | 进入下一章需要的泡泡瓶 |
|---|---|---|---|
| 1 初遇 | 「你会告诉我一些关于你的事吗？我想把它装进泡泡里。」 | 让她记住 1 件你的事；或者一起聊满 3 天 | 60 |
| 2 熟悉 | 「听说你也会下五子棋？来一局吧——输了可不许耍赖。」 | 陪她下完 1 局五子棋（输赢、平局都算，中途结束不算）；或者一起见面满 7 天 | 250 |
| 3 默契 | 「以后每天都来看看我，好不好？泡泡瓶会越来越满的。」 | 一起见面满 14 天 | 500 |
| 4 信任 | 「我总觉得，要是你能下赢我一局，我就能想起点什么。」 | 下赢她 1 局五子棋；或者一起见面满 30 天 | 800 |
| 5 羁绊 | 主线完成，泡泡瓶改叫「我们的海」 | — | — |

- **计数从哪里来**：记住的事 = 记忆手账里当前的记忆数；聊天天数 = 有过一轮提交成功的聊天的日子；见面天数 = 有过「今天第一次见面」的日子（轻点她、打开首页或发一条聊天）；五子棋 = `GomokuStore` 实际棋谱里你赢、她赢和平局的局数，主动结束的不算；下赢 = 你赢的局数。模型说"你赢了"不算。
- **锁定**：目标一旦达到就记在 `quests` 里（同时记下是哪一条路），之后记忆被忘记、棋局被清空也不会退回。
- **节奏**：泡泡瓶每天最多 35 点（另有每章剧情 +20），门槛最快在第 2、8、15、23 天左右达到。每天会来聊聊天、喂一喂的人（每天约 25 点），不下棋大约第 3、9、18、30 天依次进章，前三章被泡泡瓶或见面天数卡住、第四章被 30 天卡住；会下棋的人可以早一些走完，"下赢她"由她自己选的棋力决定（你连输三局她会降一档）。
- 五子棋战绩不加羁绊值，只用来判断这一章的事有没有做完；入口仍是首页「我们」里的「一起下五子棋」，故事页只写去哪里下，不放第二个入口。

**剧情**：到达新章节后，等她空闲时（在桌面上、亮屏解锁、没有聊天或气泡、没在播放动作、不是夜间、系统没开勿扰）逐句播放。点她或点气泡翻到下一句。顺序是：完成剧情 →「（第 N 章 · 解锁：……）」→ 她的开场白 →「（这一章：……）」。播到最后一句时记为看过，发 +20 羁绊值，写进「章节回忆」。中途被打断就下次重播。自定义人格不说开场白（里面有泡泡和五子棋的人设），只显示这一章的事。

| 进入的章 | 完成剧情 | 引用的真实素材 |
|---|---|---|
| 1 | 「我是从很深很深的海里游上来的……这里好亮呀。」 | 无 |
| 2 | 第一个装着东西的泡泡 | 最早一条记忆原文；没有记忆（靠聊天天数完成）时用「我们刚认识的那几天」 |
| 3 | 「刚才那局五子棋，我也装进泡泡里了。」→ 给你看泡泡瓶 | 上一章靠下棋完成时说这句，靠见面完成时说「这些天见到你的每一面……」；固定的（或第二早的）记忆 |
| 4 | 她写的信和一段小提琴 | 最多三条记忆，按时间串成信；没有时用相识天数 |
| 5 | 「……居然输给你了。」→ 泡泡瓶满了 → 蓝鲸现世 | 上一章靠下赢她完成时说这句，否则说「我们已经一起见了 N 面了」；相识天数、泡泡瓶、喂食次数 |

记忆原文最长 40 字。台词在 `assets/story.json`；各性格对部分台词的改写在 `assets/personas.json` 的 `storyLines`。

**关系阶段**：`AgentPolicy.relationship()` 按章节给出熟悉程度：第 1 章「刚认识不久」，第 2–3 章「已经熟悉」，第 4–5 章「老朋友」。

## 7. 界面

- **长按菜单**：聊天 / 喂食 / 动作 / 更多（大小、我们的故事、隐藏）。
- **喂食**：免费。白饭、早餐、午饭、晚饭、零食一开始就有；西瓜、冰淇淋、糖葫芦第 2 章；火锅、大闸蟹第 3 章；长寿面、一口 Token 第 5 章。今天还没喂过时，饭点她更常念叨「是啊，吃什么」；喂完半小时内更满足。
- **首页**：「我们」下面一行写清下一步，例如「第 2 章「熟悉」 · 下一步：陪她下完 1 局五子棋 0/1，或者一起见面满 7 天 3/7 · 泡泡瓶 180/250」，再加今天的互动。
- **我们的故事**：章节名和设定；「这一章要一起做的事」任务卡（她的开场白、每条路的进度和 ✓、泡泡瓶门槛和进度条、下一章解锁什么）；今天的互动、相识天数和见面天数；「收藏」里是章节回忆、动作图鉴、时令图鉴和成长记录（每一笔羁绊值的来源）。

## 8. 精简记录（2026-10-29）

v0.4.9.3 上线时还有小鱼干（喂食和便当的货币）、出门旅行（1–4 小时，收在屏幕边上）和明信片（40 个地点）。为了只留一条主线，这些都去掉了：

- 喂食改为免费，食物只按章节解锁；「小鱼干罐」去掉。
- 长按菜单的「出门」去掉，菜单回到四项。
- 第 2 章的解锁从「出门旅行」改为「一批新动作和新零食」，剧情和设定里不再提出门、明信片。
- **已安装的用户**：打开时一次性删掉成长文件里的 `fish`、`trip`、`postcards`（`Growth.simplify()`），羁绊值、章节、章节回忆、图鉴和成长记录都保留。旧版记录里看明信片得到的羁绊仍然算数，在成长记录里显示为「看明信片（旧版）」。如果升级时她正在出门、收在屏幕边上，点一下标签就会回来。
- 计划中的约定、纪念日、吃Token 彩蛋、由模型写剧情或明信片，都不再做。

## 9. 数据

- 文件 `files/growth-main.json`，原子写入，备份保存同一份已校验的新快照（被忘记的原话不会从备份里回来）。
- 主要字段：`bond`、`chapter`、`chapterAt`、`pending`（待播剧情）、`daily`（今天的计数）、`days`（见面天数 `met`、聊天天数 `chat`）、`counts`（上次读到的记忆数、下完和下赢的五子棋局数）、`quests`（已完成的章节目标：章节号 → 用的是哪条路）、`ledger`（成长记录，只存类型、时间、羁绊增量和引用，最多 500 条，更早的合并成一行汇总）、`cards`（章节回忆）、`seen`（图鉴）、`known`（已知的记忆 ID 和日记日期）、`popped`、`feeds`、`lastFed`、`lastMet`。
- 忘记记忆、清空聊天或日记：章节回忆里引用的原话换成不带原话的版本（`popped` 仍记录删掉了几条，只做统计）；羁绊值、章节和已完成的章节目标不变。手账导出包含成长记录。

**从 0.4.x 升级**（只做一次，写入 `migratedFrom`）：

```
bond = min(chatDays×15 + min(记忆数,100)×3 + 日记篇数×5 + min(互动记录数,200)×0.5, 相识天数×45)
chapter = 羁绊值够到的最高一章（之前的章节目标记为已完成）
见面天数 = 聊天天数 = chatDays
```

已经跨过的章节记为「补记」，当前章节的剧情播放一次；原有动作全部保留（含蓝鲸现世）。

**从没有章节任务的版本（0.4.9.x）升级**（`Growth.quests()`，打开文件时一次）：见面天数取成长记录里「今天第一次见面」的条数和聊天天数中较大的一个，聊天天数取聊天记录里的天数；已经跨过的章节目标记为已完成。当前章节的事如果升级前已经做到（比如已经下完过棋、已经见面满 7 天），直接算完成。原来的「相识天数」门槛去掉；已经到达的章节不变。

## 11. 设计参考

2026-10-29 对照几个成熟开源项目的源码，把"不知道下一步做什么"的主线改成任务线：

- **Habitica**（`website/common/script/content/quests/series.js`）：每个任务只有一个目标和一个计数（收集 20 个、Boss 300 血），任务连成任务线，开启条件可以是签到天数（7、22 天），每个任务有开场和完成文案。→ 每章一件事、带计数，开场白 + 完成剧情，见面天数作为签到式目标。
- **Monika After Story**（`script-story-events.rpy`、`script-affection.rpy`）：新玩法以剧情事件解锁，条件写成"等级 ≥ N **或** 已经玩过 M 局"；好感度普通互动每天有上限，一次性大事件走单独额度。→ 每章两条路；剧情回应你实际做过的事；章节剧情的 +20 不占每日上限。
- **DyberPet**（`conf.py`）：好感等级从递增门槛改成每级固定，避免越往后越慢。→ 泡泡瓶门槛从 60/250/600/1200 改成 60/250/500/800。
- **VPet**（`GameSave.cs`）：多维数值、隐藏好感、数值会掉并带来惩罚。→ 不采用：仍然只有一个数，不衰减。
