# 养成主线：深海来的小鲸鱼

> 现行规格（2026-10-29 精简后）。只有一条养成主线：**羁绊值推进章节**，章节带来剧情和新动作。
> 小鱼干、出门旅行、明信片和便当已经去掉，见 §8。

## 1. 一句话

和她相处的真实经历会变成「回忆泡泡」，攒进她的泡泡瓶。你们越亲近（羁绊值越高、认识越久），她想起的关于自己的事就越多，能做的事也越多。走到第五章，她会想起自己真正的样子。

养成的是**你们的关系**，不是她的人格。人格在初次相遇时冻结，这一点不变。

## 2. 原则

1. **只有一个数：羁绊值。** 它决定章节；泡泡数只用来展示，不是门槛。
2. **不鼓励多聊。** 每轮聊天都花用户自己的 API 费用，所以聊天一天只算一次。其余来源都是本机的免费互动。
3. **离开不扣分。** 羁绊值只增不减，没有饥饿、生病、断签。她不说让人内疚的话。
4. **模型不能加分。** 羁绊值、章节、解锁只由本机规则根据已提交的记录计算。
5. **离线可玩。** 剧情是固定剧本，插入本机记忆原文，不额外请求模型。
6. **老用户不倒退。** 已经能看到的动作不收回，已经到达的章节不回退。

## 3. 世界观

她是一条从深海游上来的小鲸鱼。深海又暗又安静，鲸鱼会把记住的事装进泡泡里，可她在海底时吐出的泡泡总是空的，因为一个人待着，没什么可以记住。

她顺着一束光游到海面，变成了现在这个小小的、看起来有点肥的样子，住进了你的屏幕。和你在一起以后，吐出的泡泡第一次装上了东西。她把它们收进**泡泡瓶**，隐约觉得瓶子装满时，会想起自己原本的样子。

结局（第五章）：她短暂地变回了一头蓝鲸（`蓝鲸现世`）。「原来我本来就这么大，才不是肥，只是还没长回去。」但她选择变回小小的样子留下来。之后泡泡瓶改叫「我们的海」，可以一直攒下去。

这和 `selfCanon` 一致：她喜欢吐泡泡，被叫「大肥鱼」时嘴上反驳；设定里不出现任何家人或同伴。

**泡泡**只指向原记录，不复制正文：一条有效记忆、一篇日记、一张章节卡各算一个。原记录被忘记、清空或删除时，泡泡「破掉」，内容不留；羁绊值和章节不受影响。

**提示词里的设定**按章节累积注入（`Growth.lore()`，放在 system 段，可缓存），只到当前章节为止：

| 章 | 设定 |
|---|---|
| 1 | 我从深海游上来，喜欢吐泡泡。泡泡是什么，我自己也还说不太清。 |
| 2 | 我开始习惯海面上的光了。我吐的泡泡里，开始装着和你有关的事。 |
| 3 | 我有一只泡泡瓶，每个泡泡里是一段和你的回忆。瓶子装满的时候，我好像会想起自己原本的样子。 |
| 4 | 深海很暗很安静，我以前一直一个人待在那里，所以以前的泡泡总是空的。 |
| 5 | 我其实是一头蓝鲸，变回去过一次，但我选择小小地留在你身边。 |

自定义人格不注入设定，剧情改用中性台词。

## 4. 羁绊值

| 行为 | 羁绊值 | 每天上限 |
|---|---|---|
| 今天第一次见面（轻点她、打开首页或发出一条聊天） | +5 | 1 次 |
| 今天聊满 3 轮（只算提交成功的你的轮次；主动消息、历史检索提问不算） | +10 | 1 次 |
| 喂食 | +2 | 3 次 |
| 摸摸（连戳惹她生气的那次不算） | +1 | 5 次 |
| 新记下一件事（当天写入的记忆） | +3 | 3 次 |
| 章节剧情播完 | +20 | 每章一次 |

日常每天最多 35 点。一天的分界按手机时区；时间往回拨不重复发奖。

## 5. 章节

羁绊值和相识天数（从初次相遇算，第一天是第 1 天）**都要**达到：

| 章 | 名称 | 羁绊值 | 相识天数 | 解锁 |
|---|---|---|---|---|
| 1 | 初遇 | 0 | 1 | 喂食和第一批小动作 |
| 2 | 熟悉 | 60 | 3 | 一批新动作和新零食 |
| 3 | 默契 | 250 | 10 | 一批新的玩耍动作 |
| 4 | 信任 | 600 | 30 | 表演类动作（小提琴、笛子、魔术……） |
| 5 | 羁绊 | 1200 | 60 | 蓝鲸现世，泡泡瓶变成「我们的海」 |

天天来、会聊天的用户（每天约 25 点）大约第 3、10、30、60 天依次进章，被天数卡住；每天只打开、喂三次的用户（每天 11 点）大约第 6、23、55、110 天。

**剧情**：到达新章节后，等她空闲时（在桌面上、亮屏解锁、没有聊天或气泡、没在播放动作、不是夜间、系统没开勿扰）逐句播放。点她或点气泡翻到下一句。播到最后一句时记为看过，发 +20 羁绊值，写进「章节回忆」。中途被打断就下次重播。

| 章 | 剧情 | 引用的真实素材 |
|---|---|---|
| 1 | 「我是从很深很深的海里游上来的……这里好亮呀。」 | 无 |
| 2 | 第一个装着东西的泡泡 | 最早一条记忆原文；没有记忆时用「我们刚认识的那几天」 |
| 3 | 给你看泡泡瓶 | 固定的（或第二早的）记忆；没有时用相识天数 |
| 4 | 她写的信和一段小提琴 | 最多三条记忆，按时间串成信；没有时用相识天数 |
| 5 | 蓝鲸现世 | 相识天数、泡泡数、喂食次数（本机统计） |

记忆原文最长 40 字。台词在 `assets/story.json`。

**关系阶段**：`AgentPolicy.relationship()` 按章节给出熟悉程度：第 1 章「刚认识不久」，第 2–3 章「已经熟悉」，第 4–5 章「老朋友」。

## 6. 动作解锁

- **始终可用**：作息、睡眠、点击回应、拖动、工作状态、情绪兜底动作，以及节日和季节动作（本来就按日期出现，第一次看到时记进时令图鉴）。
- **按章节解锁**：没解锁的不进待机，动作菜单里显示为灰色的「第 N 章解锁」。

| 章 | 动作 |
|---|---|
| 1 | 鲸鱼吐泡泡特效、大口吃零食、用鲸鱼尾巴拍打地面、女仆屈膝礼仪、原地重力下蹲压缩、小幅度原地360度旋转展示 |
| 2 | 吃西瓜、吃冰淇淋融化、吃糖葫芦、照镜子、原地专心玩魔方、吹气球、抽陀螺、踢毽子、三球抛接、轻快摇摆舞 |
| 3 | 下五子棋、原地蹲下玩玩具汽车、玩游戏气急败坏、原地跳跃抓碎头顶物品、骑木马、荡秋千、撸猫、可爱宅舞、涮火锅、吃大闸蟹 |
| 4 | 小提琴演奏、吹笛子、扑克魔术、变鸽子、凭空生花、动物环绕、优雅女仆舞、整体换装试色、拆礼物 |

## 7. 界面

- **长按菜单**：聊天 / 喂食 / 动作 / 更多（大小、我们的故事、隐藏）。
- **喂食**：免费。白饭、早餐、午饭、晚饭、零食一开始就有；西瓜、冰淇淋、糖葫芦第 2 章；火锅、大闸蟹第 3 章；长寿面、一口 Token 第 5 章。今天还没喂过时，饭点她更常念叨「是啊，吃什么」；喂完半小时内更满足。
- **首页**：名字下面一行「第 N 章「名」 · 羁绊 X/Y」和今天的互动，点开是「我们的故事」。
- **我们的故事**：当前章节和设定、进度条、离下一章还差多少；泡泡瓶只显示总数和破掉的数量（泡泡只指向原记录：记忆和日记在「记忆手账」里看，不在这里按类型再列一遍）；「收藏」里是章节回忆、动作图鉴、时令图鉴和成长记录（每一笔羁绊值的来源）。

## 8. 精简记录（2026-10-29）

v0.4.9.3 上线时还有小鱼干（喂食和便当的货币）、出门旅行（1–4 小时，收在屏幕边上）和明信片（40 个地点）。为了只留一条主线，这些都去掉了：

- 喂食改为免费，食物只按章节解锁；「小鱼干罐」去掉。
- 长按菜单的「出门」去掉，菜单回到四项。
- 第 2 章的解锁从「出门旅行」改为「一批新动作和新零食」，剧情和设定里不再提出门、明信片。
- **已安装的用户**：打开时一次性删掉成长文件里的 `fish`、`trip`、`postcards`（`Growth.simplify()`），羁绊值、章节、章节回忆、图鉴和成长记录都保留。旧版记录里看明信片得到的羁绊仍然算数，在成长记录里显示为「看明信片（旧版）」。如果升级时她正在出门、收在屏幕边上，点一下标签就会回来。
- 计划中的约定、纪念日、吃Token 彩蛋、由模型写剧情或明信片，都不再做。

## 9. 数据

- 文件 `files/growth-main.json`，原子写入，备份保存同一份已校验的新快照（被忘记的原话不会从备份里回来）。
- 主要字段：`bond`、`chapter`、`chapterAt`、`pending`（待播剧情）、`daily`（今天的计数）、`ledger`（成长记录，只存类型、时间、羁绊增量和引用，最多 500 条，更早的合并成一行汇总）、`cards`（章节回忆）、`seen`（图鉴）、`known`（已知的记忆 ID 和日记日期）、`popped`、`feeds`、`lastFed`、`lastMet`。
- 忘记记忆、清空聊天或日记：泡泡破掉，章节回忆里引用的原话换成不带原话的版本；羁绊值和章节不变。手账导出包含成长记录。

**从 0.4.x 升级**（只做一次，写入 `migratedFrom`）：

```
bond = min(chatDays×15 + min(记忆数,100)×3 + 日记篇数×5 + min(互动记录数,200)×0.5, 相识天数×45)
chapter = 同时满足羁绊值和天数门槛的最高一章
```

已经跨过的章节记为「补记」，当前章节的剧情播放一次；原有动作全部保留（含蓝鲸现世）。
