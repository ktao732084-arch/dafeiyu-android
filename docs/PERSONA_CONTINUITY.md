# 人格连续性：轻量改动

独立分支 `codex/persona-continuity-lite`，开始时从 GitHub `origin/main` 的 `10c1a8d` 建立；收尾时同步了最新主分支 `278fca4` 的气泡分段与养成过渡修复。保留最新的性格分层、养成、主动安排、更新与双端发布流程，不从已发布的旧 APK 或早期实验分支恢复代码。本轮不修改版本号、不合并主分支、不发布 APK。

重新核对了此前 Alice 1.3.45 安装包的静态调研，借鉴“理解有适用条件、状态延续有原因、表达共用人格”的机制。没有移植其代码、提示词、九维认知树或 OCC 情绪引擎；此前调研也没有证明它的长期对话效果。

## 实现

1. **共用表达**：五种风格各有本地问候、喂食、出门与回来台词；章节中带明显默认性格的句子可按预设替换。替换必须保留占位符，用户原话与引用来源不改，删除时仍使用无引用回退。日记带冻结人格与同一份性格细节。自定义人格不附加预设风格；没有额外模型调用。
2. **相处理解按场景使用**：增加有限的 scene/topic 字段，沿用日记的逐字依据校验。普通聊天按本轮文字匹配，最多注入三条；工作倾诉的“先听”不会自动用于工作求建议或人际场景。未识别的场景保守跳过限定条目。仍受记忆/日记开关控制，不扩大数据收集，也不改变忙闲调度。
3. **心情连续性**：同一次模型回复补充 mood_changed 布尔值。false 保留原时钟及起因；true 才开始新状态并记录来源轮次。旧协议的同类情绪也不重复续期；纯文本及无效标记保守沿用。界面收到的情绪与存储一致。保留既有衰减和删除规则。

新事件的情绪判断仍由当前聊天模型作出，程序只管理连续性；不声称实现了客观情绪测量。场景识别使用小范围中文关键词，可能漏掉较隐晦表达，未识别时不强行套用。
