## 已确认的手机行为

- 新安装默认内置引擎；升级时仅保存过旧服务地址和开关，不会自动启用Python路径。
- 主记忆设置无需填写服务器地址或令牌。模型辅助开关默认开启，使用已配置的手机模型和Key。
- 无模型时，「记住：」仍能写入、明确更正、归档；原话、来源、日期和历史由本机保存。
- 模型只能选择已有ID或建议新增/重复/取代；无效引用、格式错误、取消和迟到结果不能破坏或复活已删除记忆。批量判断全部校验后才应用。
- 人格依旧只在初始化时决定，不随记忆或升级重新选择。

## 未覆盖的边界

Robolectric执行实际编译类与APK资源，是JVM中的Android框架测试，不证明已在真实手机安装。Android Keystore使用测试Provider，模型响应使用受控替身；原生离线规则是真实执行。

原生模型语义选择采用当前聊天模型，不是上游ONNX向量方案；本次没有用真实云模型独立复测语义质量，不能把上游164/166直接作为手机端成绩。规则模式的21项不足涉及隐含变化、同义表达及部分过时信息。

真机安装、浮窗、视频解码、系统Keystore、后台与耗电仍待验收。之前版本记录保留在 [0.3.0](docs/VALIDATION-0.3.0.md) 和 [0.2.0](docs/VALIDATION-0.2.0.md)。
