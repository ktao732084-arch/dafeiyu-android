# 自然气泡与棋局入口验收 · 2026-10-29

用户反馈：模拟器的聊天仍有较长整段，讨论五子棋战绩也会出现对局入口。检查发现模拟器运行code16的旧开发包；主分支聊天入口仍直接匹配“五子棋”关键字。

本轮在当前主分支上采用v3分段：保留短句和引号等结构，在自然停顿处无损拆分，增加省略号、破折号与较短逗号分句。旧v1/v2展示计数按各自原算法解释，只重排已经展示的前缀。聊天和桌宠使用同一分段模块。

对局入口按整轮已展示内容与用户原话判断，仅明确邀请/想玩时显示一次；战绩、规则、引用、拒绝、推迟和未展示邀请不触发。使用保守本地短语规则，不声称覆盖任意自然语言意图，也不增加模型请求。
