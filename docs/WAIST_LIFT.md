# 头部 / 后腰提起与默认动作衔接 · 2026-10-29

同一未发布批次，保留 0.4.9.4 / code18。基于 `PET_LIFT.md` 的通用提起，增加独立后腰姿态与受力反馈。

## 区域与素材

- 按下时记录身体相对位置，上部用原悬空视频，下部用后腰姿态。拖动途中不重新判定部位；静止长按仍开菜单。
- 后腰姿态是新增透明 PNG，具体来源、内置 image_gen 生成提示词、受力点与脚部锚点见 [素材记录](WAIST_LIFT_ASSET.md)。原106段视频未改动。
- 新姿态按原角色实际高度缩放；后腰围裙结对准手指的初始抓取点。放下按旋转后的脚部锚点定位，短促拖动还会混合落点，避免尚未完全出现的新姿态把角色突然移走。
- 吐槽上下文携带真实 `grabRegion=head/waist`，沿用冻结人格、原称呼、一次提起一次请求与取消规则。

## 物理与过渡

- `SuspensionMotion` 根据抓取点位移计算加速度，再用重力参考方向与阻尼弹簧求摆动。停手后收稳，不用固定正弦不断左右摇。角度上限14°，头部使用较小幅度；衣料仅保留轻微局部活动。
- 单次积分步长不大于8ms，过滤输入抖动；窗口暂停后的大时间间隔不制造突发冲量。
- 标称220ms进入、240ms退出，遵循系统动画速度设置。退出时保留默认画面做过渡，结束后再恢复视频，避免在混合期间重建解码器；温和放下有很轻的压缩回弹，快速甩出不播放落下压缩。
- 过渡期间同时容纳两种姿态的绘制范围；结束后恢复普通边界、透明度、旋转、缩放和视频播放。自动小动作、章节剧情等待过渡结束。
- 新手势会结束旧过渡；隐藏、收边、锁屏、服务销毁会清理残留视图和动画回调。关闭系统动画时直接完成状态切换。

这是基于二维姿态与受约束摆动的视觉反馈，不是三维骨骼或布料仿真。
