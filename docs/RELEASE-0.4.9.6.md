# 大肥鱼 0.4.9.6 · 更正记忆与桌宠互动

本次显示版本号仅递增最后一位，Android versionCode 升为20。沿用原签名覆盖安装，保留模型配置、人格、聊天、记忆、成长和棋谱。

- **更正记得住**：补齐常买、常喝等习惯及明确改期的保存；“没怎么喝”不再误判成问题。更正连同地点、糖分等范围说明保存，旧事实进入历史，改期按新日期生效。
- **少记错内容**：复述指令、代码练习结束语等不当成用户事实；旧同类非手动记录也不进入普通事实召回，原记录仍保留。
- **拦截乱码**：严格检查网络编码和回复文字；发现损坏最多重试一次，仍失败就保留草稿，不保存损坏回复。历史乱码不再作为可引用的回答喂给模型。
- **保持性格，改善表达**：保留傲娇、偏好与原有人格，复述事实时直接说准确结果；小声嘀咕即使返回为末尾标签也会放入专用区域，关闭开关仍有效。用户要求原样输出的代码保留。
- **桌宠更有回应**：汇总主分支的短气泡、四宫格长按菜单、扩展点击动作，以及按头部/腰部区分的提起姿态与阻尼摆动。提起时的回应使用真实互动信息，迟到结果不会打断松手后的状态；互动内容仍不插进普通聊天。
- **日常相处与设置**：汇总小声嘀咕、她的今天、共同经历与记忆手账，以及精简后的模型连接页。

润色保真机制继续保留，无法确认时可能返回原句。自然中文仍可能偶尔拗口，不把保留原意或通过测试理解为模型永不出错。

新版同步提供 GitHub Release 和国内 HTTPS 更新源。已安装用户可在「关于 → 检查更新」获取，无需重新配置模型或重新选择人格。

验证包括 Android 15 模拟器、实际产品 DEX、独立运行时和框架回归。此前修复阶段用既有真实模型完成40轮迭代聊天，发布包另作升级及真实连接验证；不代表全部实体手机或全部模型。最终安装包绑定记录见 [VALIDATION.md](https://github.com/ktao732084-arch/dafeiyu-android/blob/v0.4.9.6/VALIDATION.md)。
