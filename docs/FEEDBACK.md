# 问题反馈

首页「关于 → 问题反馈」在 App 内打开大肥鱼的[兔小巢](https://txc.qq.com)反馈页。兔小巢是腾讯免费的产品反馈服务，国内访问稳定。用户写下问题，可附截图，点发表即可，不需要注册或登录。开发者在兔小巢后台，或在微信里收通知和回复。

## 为什么用兔小巢

- **不需要服务器**：不用自己部署和维护任何服务。
- **安装包里没有凭据**：App 只知道一个公开的反馈页地址，没有 GitHub Token 或邮箱密码可被拆出来。
- **能回复**：开发者的回复用户回到同一页就能看到；用户也能补充截图和细节。

## 用户身份与发送的内容

- **身份**：第一次打开时，每台手机生成一个随机 `openid`，存在本机设置里。App 用它和一个短昵称（如「鱼友3f2a」）、她的立绘作为头像登录兔小巢。所以用户不用登录，回来还能看到自己发过的反馈和回复。卸载重装后是新身份。
- **随页面带上**：App 版本、Android 版本和机型，显示在每条反馈旁边，方便排查。
- **不会发送**：聊天、记忆、Key 和模型地址。用户自己写进反馈的内容除外，所以页面顶部提醒了这一点。

## 开发者设置（一次性，约 2 分钟）

1. 打开 https://txc.qq.com ，用 QQ 或微信登录，创建一个产品，比如「大肥鱼」。
2. 在产品的地址 `https://support.qq.com/product/<编号>` 里拿到编号。
3. 把完整地址写进 `assets/update-channel.json` 的 `feedback_url`，例如：
   ```json
   {"manifest_url":"https://81.70.79.133/dafeiyu-updates/stable.json","feedback_url":"https://support.qq.com/product/123456"}
   ```
   只接受这种格式。`build.ps1 -UpdateUrl` 只改更新地址，不动反馈地址。
4. 在兔小巢后台打开新反馈的微信通知。

在没填地址的版本里点「问题反馈」，会提示“这个版本还没有配置反馈页面”。

## 验证

- `FeedbackTest` 在核心测试里，覆盖地址格式、随页面带的字段、登录字段和站外链接处理。
- `UsabilityUiTest.feedbackOpensTheBoardOrSaysThereIsNone` 覆盖入口和身份只生成一次。
- 真机上还要确认几件事：页面能打开且已登录，能选截图，返回键先后退网页再关闭，外部链接用浏览器打开。
