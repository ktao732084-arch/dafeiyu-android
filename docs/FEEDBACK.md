# 自建问题反馈（PR #27，待随 App 发布）

2026-10-30 按用户要求，从兔小巢改为使用项目自己的北京服务器。保留 PR #27 的 App 内完整页面、每台手机独立身份、截图选择和返回行为；无需用户注册，也不需要填写反馈地址。

## 用户流程

首页「关于 → 问题反馈」打开自建页面，填写内容，选填联系方式和一张截图，点击发送。在「我的反馈」查看自己的记录、开发者回复，也可以补充说明。刷新或重新进入会读取更新；没有邮件、微信或推送通知。

- 地址：`https://81.70.79.133/dafeiyu-feedback/`，由 `assets/update-channel.json` 的 `feedback_url` 提供；更新地址保持不变。
- 安装身份：首次打开时在 App 私有设置生成 UUID。通过 HTTPS 初始导航请求头换取签名的 HttpOnly / Secure / SameSite 会话 Cookie，凭据不进入 URL、网页脚本或服务器日志。清除数据/卸载后没有账号恢复机制。
- 随页面建立会话的字段：App 版本（含 code）、Android 版本和机型。实际提交只包含用户写的内容、选填联系方式及主动选择并发送的截图；不自动附带聊天、记忆、模型地址或 Key。
- 反馈与截图仅属于对应安装身份，其他身份不能列表或读取。开发者通过服务器 SSH 管理工具查看、回复和标记已处理，不在网页开放管理员入口。
- 文字草稿保存在 WebView 本地存储中，网络失败保留内容和提交编号；同一编号重试不重复新增。关闭页面后需重新选择截图；如果已经发送成功，可先刷新「我的反馈」确认。
- 截图限一张、3 MB、1200 万像素以内的 PNG/JPEG/WebP。服务器解码校验并重新编码为 JPEG，去除 EXIF 等元数据，缩到最长 2400 像素。

## 服务端

`Nginx :443 → 127.0.0.1:8790 → Python 3.11 + SQLite`。文字、回复、截图及毫秒时间戳保存在 `/var/lib/dafeiyu-feedback/feedback.sqlite3`，不进入 GitHub Issues 或第三方反馈服务。服务开机启动，复用原 HTTPS 证书与续期流程。

客户端沿用 PR 的 WebView 外壳；导航和子资源限制在已配置的 HTTPS 源及 `/dafeiyu-feedback/` 路径内。没有 JavaScript 原生桥、任意文件访问或第三方登录页面。具体安装、管理、限额、备份与回滚见 [服务端运维](../deploy/feedback/README.md)。
