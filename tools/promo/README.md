# 宣传片

`render_promo.py` 用 `assets/main` 里的角色动画合成宣传片，`soundtrack.py` 现场合成配乐与音效（不使用第三方音乐）。

```bash
python3 tools/promo/render_promo.py --font-dir <字体目录> [--phone-dir <真机录屏目录>]
```

- 字体目录里放同一套中文字体的 400 / 700 / 900 三个字重（文件名含 `400`、`700`、`900`，woff2/ttf/otf 均可），例如 Noto Sans SC。缺字会直接报错。
- 输出到 `docs/promo/`：`dafeiyu-promo.mp4`（默认 1920×1080、60 帧/秒，H.264 High + AAC 192k，可直接上传各平台）、`dafeiyu-promo.webp`（README 用的无声动图）、`cover.png`。
- 画面按 1280×720 排版，`--scale` 决定输出倍数（1.5 即 1080p，1 即 720p），`--fps` 设帧率，`--crf` 设画质（越小越清晰，默认 16）。`--jobs` 按 CPU 核数并行分段渲染后无损拼接。
- 角色动画原片每半边 640×480、30 帧/秒，放大时用 Lanczos 并对彩色半边轻微锐化；1080p 下角色仍会比文字略软。录屏片段不做补帧：试过运动补偿插帧，她切换动作时会出现重影。
- 依赖 ffmpeg、numpy、Pillow。

## 加入真机录屏

`--phone-dir` 指向放录屏原文件的文件夹，剪辑方式写在 [phone_cut.json](phone_cut.json)：每组镜头有标题、副标题和左右两台手机，每台手机列出要用的片段（文件名、起止秒数）。片段按顺序拼接后整体变速，正好填满一组的时长（默认 6.5 秒）。真机部分插在标题之后，后面的段落和配乐自动顺延。

录屏原文件不放进仓库，只提交剪辑表和渲染好的成片。

录制建议：

- 竖屏、系统自带录屏即可；每段剪成 6～8 秒，片头片尾不要停在录屏控制条上。
- 推荐镜头：她浮在桌面或其他 App 上待机、轻点后的回应动作、长按菜单喂食、拖动她到屏幕边缘、聊天页短气泡逐条出现。
- **不要拍到真实聊天、API Key、余额、通知内容和个人信息**（见 [AGENTS.md](../../AGENTS.md)「真实聊天截图与Key不放公开仓库」）。建议开勿扰模式，用全新安装或专门的演示对话。
