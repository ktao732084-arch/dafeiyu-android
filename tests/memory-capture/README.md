# 规则兜底写入的评测语料

`+` 开头是值得记住的话，`-` 开头是日常闲聊。`NativeMemoryEngine.autoFacts` 判断一句话是否在模型没有摘抄时也自动记下。

- `tuning.txt`：调规则时用的语料（48 条事实，60 条闲聊，包括专门针对新规则的反例）。
- `blind.txt`：规则定稿后才写、只测过一次的盲测语料（25 + 25），没有据此再改规则。首次结果 22/25 抓取、2/25 误记（「我在地铁上」「无聊死了」）。

`MemoryCaptureTest` 在这两份语料和记忆引擎的 84 个共享场景上检查抓取率与误记率不退步。改规则时，盲测数字只能作为参考，不要为了它调规则，否则需要另写新的盲测语料。
